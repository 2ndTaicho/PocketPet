
# Pocket Pet

A cozy virtual pet game built with React, JavaScript, and CSS.

Pocket Pet lets players adopt their own little companions, care for them, decorate their homes, and play mini-games. The game is designed with soft colors, cute illustrations, and interactive features.

## Features

- Adopt kittens, puppies, and bunnies
- Take care of multiple pets
- Feed, bathe, rest, and play with pets
- Explore four different rooms
- Customize pets with accessories
- Buy decorations in the shop
- Play three mini-games to earn coins
- Level up and unlock achievements
- Claim daily rewards
- Discover different pet personalities
- Interact with animated pets
- Write entries in a pet diary
- Check pet wellness and give treats
- Change the weather and time of day
- Customize sound effects and volume
- Reduce animations in Settings
- Save progress automatically
- Play on desktop and mobile devices

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Getting Started

Install Node.js before running the project.

Open the project folder in VS Code and run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local address shown in the terminal.

## Build

To create a production build:

```powershell
npm.cmd run build
```

## Saving Progress

Pocket Pet uses browser localStorage to save pets, coins, accessories, diary entries, and settings.

Progress is saved on the current browser and device. Clearing browser site data can remove saved progress.

## About the Project

Pocket Pet was created as a portfolio project to practice React components, state management, interactive interfaces, CSS animations, responsive design, and browser storage.
